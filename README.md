# 🧩 WordSearch Studio: Kids Puzzle Generator

A simple, fun, and easy-to-use web application that lets parents and teachers create custom, printable Word Search puzzles for kids aged 8 to 10 (Grades 2 to 5). 

Designed to fit perfectly onto standard **US Letter (8.5" x 11")** paper without awkward page breaks or formatting issues!

---

## ✨ Features

- **Kid-Friendly Presets:** Quickly load pre-made topics like *Wild Animals*, *Space Explorers*, *Superheroes*, and *Ocean Life*.
- **Fully Customizable:** Input your own custom spelling words, vocabulary lists, or themed words.
- **Adjustable Difficulty:** 
  - Change grid sizes (`10x10`, `12x12`, `15x15`).
  - Toggle word search directions (Horizontal, Vertical, Diagonal, and Backwards).
- **Print & PDF Ready:** Optimized for printing directly from your browser with optional student header (Name/Date) and a separate Answer Key page.

## 🚀 How to Use / Run This Project

You don't need any complex programming setup to run this!

### Option 1: Open Directly in Your Web Browser (Easiest)
1. Download the file named `index.html` from this repository.
2. Double-click the downloaded `index.html` file.
3. It will open directly in your web browser (Chrome, Edge, Safari, Firefox)—no internet connection or web server required!

### Option 2: Host Free on GitHub Pages (Share with Parents & Teachers)
If you want to host this online so anyone can visit your link:
1. Fork or upload this repository to your GitHub account.
2. In your GitHub repository, go to **Settings** > **Pages**.
3. Under **Build and deployment** -> **Branch**, select `main` (or `master`) and click **Save**.
4. GitHub will give you a live website link in 1–2 minutes!

### Option 3: Access this utility directly from below link:
https://bbdvengineering.github.io/Word_Search_Puzzle_Creator/

## 🖨️ Printing Tips for Best Results

1. **Paper Size:** Set your printer paper size to **Letter (8.5 x 11 in)**.
2. **Margins:** Select **Default** or **None/Minimal** in the browser print window.
3. **Background Graphics:** Ensure **"Background graphics"** is checked in your browser's print preview settings if you want background colors to show up clearly.
